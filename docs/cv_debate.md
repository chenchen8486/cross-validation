# /cv_debate — 多轮闭环博弈

此命令是 `/cv debate` 的快捷方式，功能与逻辑完全一致。

## 执行方式

请使用 `Read` 工具读取文件 `docs/cv.md`，然后严格按照其中【Debate 向导模式】的完整步骤执行。

**参数处理规则**：

- `$ARGUMENTS` 直接作为 debate 模式的参数（**不需要**去掉 `debate` 前缀）。
- 如果 `$ARGUMENTS` 的第一个参数看起来像路径（包含 `/`、`.`、盘符如 `C:`、或反斜杠 `\`），则将其作为**初始文件路径**。
- 剩余部分（如果有）作为**初始定向指令**。
- 如果没有参数，则**初始文件路径为空**，后续交互询问。

**路径兼容性规范**：

- **接收阶段**：无论用户输入什么路径格式，都原样保留传递给 `Read` 和 `Bash`。
- **验证阶段**：始终使用 `Read` 工具验证路径是否存在。
- **失败处理**：`Read` 返回"文件未找到"时，绝不要猜测路径或自动修正，必须向用户明确报告并请求重新输入。
- **传递阶段**：在组装 `Bash` 命令时，路径必须用**双引号 `"`** 包裹。
